# Support

## Usage questions

Search the README, documentation, and existing issues first. If the answer is
not available, open a GitHub issue with the `question` label and include:

- the package version and Python version;
- the command or API being used;
- a minimal, non-sensitive example;
- the expected and actual result;
- the relevant traceback or output.

Maintainers provide support on a best-effort basis. There is no guaranteed
response time and no support for making investment decisions.

## Bugs and data-quality concerns

Use the corresponding issue form. Remove API keys, account identifiers,
positions, transaction history, and proprietary data before posting.

## Security

Do not request security support in a public issue. Follow the private reporting
instructions in [SECURITY.md](SECURITY.md).
